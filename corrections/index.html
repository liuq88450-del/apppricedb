Corrections

Pages get things wrong. This is the record of what we got wrong on this site and when we fixed it.

2026-11-09

  • Gorgias vs Help Scout — the summary bullet said Help Scout wins at 3 and 5 seats "from 500 tickets upward". The computed matrix gives Help Scout 3 seats from 500 tickets and 5 seats from 1,000; at 500 tickets with 5 seats, Gorgias is cheaper ($140 against $225). Sentence fixed to match the table.

2026-11-06

  • Gorgias cost guide — first draft said Starter at 500 tickets was "nearly triple" Basic. It is $190 against $140, about 36% more. Fixed before publishing.
  • Gorgias cost guide — first draft put the Basic/Pro crossover at 1,800 tickets; the arithmetic puts it near 1,050. Fixed before publishing.
  • Gorgias vs Help Scout — first draft claimed Help Scout won only one combination; the computed matrix shows it wins five of fifteen. Fixed before publishing.
  • Site build — the first GitHub Pages build failed (Jekyll), leaving new pages at 404. Fixed with a .nojekyll file.

How corrections happen

  • Every number is checked against the vendor's own page before publishing; if it cannot be checked, the page is not published.
  • When a reader finds an error, the fix is made and logged here with the date, not quietly edited.
  • Price changes are logged in the price archive instead, because a changed price is not an error.
