What the price tag hides

  • Vitals bills by order volume, not by feature: the feature set does not change between tiers, only the price.
  • Because it bundles 40+ apps, the comparison that matters is Vitals against the sum of the individual apps it replaces, not against any single app.

How to read this

Start from the billing unit, not the headline price. If your store sits above the entry tier, the number that matters is the next tier up, which is why we publish the unit rather than a single "starting at" figure.
